## 2. SCOPE OF WORK (SOW)

### 2.1 Objectives
- Automate content creation, scheduling, and publishing for Edummu Trekkers across all major social media platforms
- Establish a consistent brand voice that reflects the adventure/trekking culture of Arunachal Pradesh
- Reduce manual effort in content creation to near-zero through AI-powered automation
- Build audience engagement and brand awareness for Edummu Trekkers

### 2.2 Platforms Covered
| # | Platform | Content Type |
|---|----------|-------------|
| 1 | Instagram | Reels, Carousels, Stories, Feed Posts |
| 2 | Facebook | Posts, Stories, Events |
| 3 | LinkedIn | Professional travel/adventure posts |
| 4 | Twitter/X | Short updates, threads, engagement |
| 5 | YouTube Shorts | Short-form trek video highlights |

### 2.3 Deliverables

| # | Deliverable | Description |
|---|-------------|-------------|
| 1 | Brand Voice Configuration | Custom `memory.md` file with Edummu Trekkers' tone, voice, audience, and style |
| 2 | Content Templates | Platform-specific templates for different content types (trek announcements, behind-the-scenes, tips, testimonials) |
| 3 | Automated Workflow | Fully functional Claude Code + Blotato pipeline for content generation & publishing |
| 4 | Content Calendar | 30-day rolling content calendar with automated scheduling |
| 5 | Visual Templates | Branded visual/infographic templates configured in Blotato |
| 6 | Account Integration | All social media accounts connected via Blotato MCP |
| 7 | SOP Document | Standard Operating Procedure for running the system |
| 8 | Training Session | 2-hour training for the client team on operating the system |

### 2.4 Content Pillars for Edummu Trekkers
1. **Trek Highlights** - Route showcases, summit stories, scenic photography
2. **Safety & Tips** - Trekking preparation, gear guides, altitude tips
3. **Arunachal Pradesh Culture** - Local culture, tribes, food, festivals
4. **Customer Testimonials** - Reviews, trek stories from past trekkers
5. **Behind the Scenes** - Team prep, campsite setup, logistics
6. **Promotional** - Package announcements, early bird offers, seasonal treks
7. **Educational** - Flora/fauna, geography, environmental awareness

### 2.5 Posting Frequency (Recommended)

| Platform | Posts/Week | Content Type |
|----------|-----------|--------------|
| Instagram | 7-10 | 3 Reels + 2 Carousels + 2-3 Stories daily + 2 Feed |
| Facebook | 5-7 | Posts + Events + Stories |
| LinkedIn | 3-4 | Professional adventure/tourism content |
| Twitter/X | 7-10 | Daily updates, threads, engagement |
| YouTube Shorts | 2-3 | Trek highlight clips |

**Total: ~25-35 pieces of content per week (automated)**

### 6.3 Automation Workflow (Daily Operation)

```
Step 1: Open VS Code → Launch Claude Code
Step 2: Prompt: "Generate this week's content for Edummu Trekkers 
         based on the content calendar. Use my brand voice."
Step 3: Claude reads memory.md + templates → Generates all posts
Step 4: Review generated content (optional edit)
Step 5: Prompt: "Create visuals for this week's carousel posts 
         and schedule everything per the calendar"
Step 6: Claude uses Blotato MCP → Schedules all posts
Step 7: Verify in Blotato dashboard → Done!
```

**Time Required Per Week (After Setup): 30-60 minutes**

## 7. BRAND VOICE CONFIGURATION (Sample for Edummu Trekkers)

The following will be saved in `memory.md`:

```markdown
# Edummu Trekkers - Brand Voice

## Tone
- Adventurous, warm, and grounded
- Inspirational but not preachy
- Friendly like a fellow trekker, not corporate

## Audience
- Age 22-45, urban professionals seeking adventure
- First-time and experienced trekkers
- Nature lovers interested in Northeast India
- Budget-conscious adventure seekers

## Language Style
- Mix of English and occasional Hindi phrases
- Use trekking terminology naturally
- Short, punchy sentences for Instagram/Twitter
- Longer storytelling format for LinkedIn/Facebook

## Do's
- Share real stories and experiences
- Highlight Arunachal Pradesh's unique beauty
- Include practical tips and info
- Use nature-inspired emojis sparingly (🏔️ 🌄 🥾 ⛺)
- Tag locations when relevant

## Don'ts
- Don't use overly formal language
- Don't oversell or use pushy sales language
- Don't post without context or storytelling
- Don't use more than 3-4 emojis per post
- Don't ignore environmental messaging

## Hashtag Strategy
Primary: #EdummuTrekkers #ArunachalTrekking #NortheastIndia
Secondary: #TrekkingIndia #AdventureTravel #HimalayanTreks
Seasonal: (varies by trek/season)
```
